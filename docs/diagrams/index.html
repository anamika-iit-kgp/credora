Credora · Architecture diagrams

Pre-approved corporate loan offers for Sapphire Bank, analysed in Exasol. Four views, from the big picture down to one analysis run.

1 · Big picture

  • Sources (bank databases and 3rd party data APIs) into Exasol's layers, out to the web app, four roles, Claude and the CRM.

2 · AWS deployment

  • ap-south-1 with the VPC, subnets, security groups, both domains on Route 53, ports and protocols, S3, Secrets Manager, IAM.

3 · Inside Exasol

  • Runtimes and BucketFS, virtual schemas, API and ML UDFs, staging and purge, Lua, results, roles, preprocessor and semantic layer.

4 · Analysis flow

  • RUN_ANALYSIS step by step with source, rows and timing, ending in the PREFERRING top 50 and the CRM export.

5 · Roles and AI access

  • Four roles as rings of data, Ask Credora logging in to Exasol as the role's own user through the MCP server, and what each role and its AI can and cannot do.

Each diagram is a single HTML file with inline SVG. The ⋯ menu on a diagram exports it as PNG or PDF. Sapphire Bank is fictional and all data is synthetic.
