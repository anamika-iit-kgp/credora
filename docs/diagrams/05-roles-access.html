Admin · CREDORA_ADMIN

  • Sees everything, read-only, drafts included. Results, the three bank databases, raw CIBIL/GST/AA, loan status, audit
  • Can do bank manager. Generate, append and purge mock data, approve or reject policy proposals and model activations, audit, sources
  • Cannot run the analysis, train, what-if, assign companies, negotiate, sanction, decide own requests
  • AI can join Oracle + MySQL + PostgreSQL in one query, read raw API data, run log, semantic view
  • AI cannot write anything, answer off-topic questions

Data scientist · CREDORA_DATASCI

  • Sees same data as admin, read-only, drafts included, with loan status read-only
  • Can do run the analysis and publish it to loan operations, train models and request activation, what-if and propose policy
  • Cannot activate a model or change policy without the admin, generate data, assign, negotiate, sanction
  • AI can model registry (AUC, Gini, features), features vs grades, past loans in VS_LOS, raw API data
  • AI cannot write anything, answer off-topic questions

Loan operations · CREDORA_LOANOPS

  • Sees published runs with all results and the three bank databases, loan status, but not the raw 3rd party data
  • Can do assign companies to relationship managers (single, bulk, reassign), every report, verify and sanction escalations
  • Cannot run the analysis, see drafts, generate data, train, what-if, negotiate
  • AI can KYC from the customer master joined with decisions, core-banking credits, hard-fail counts
  • AI cannot read CREDORA_STAGE (Exasol refuses), write anything

Relationship manager · CREDORA_RM

  • Sees only the companies assigned to her, at full detail, with report, features, unmasked PAN and GSTIN
  • Can do negotiate within the limit (above it, escalated), log loan status (Contacted to Disbursed, or Not interested), credit memo
  • Cannot see any other company, bank databases, raw API data, run, publish or assign anything
  • AI can headroom, lowest ROI and RAROC, her companies by loan status, through the V_RM_* views
  • AI cannot read any other company. Exasol filters the rows on CURRENT_USER and refuses DECISIONS itself
