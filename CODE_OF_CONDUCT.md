# Code of conduct

Credora is a small open-source project. Everyone who takes part, in issues, pull requests or discussions, is expected to be respectful and patient, to assume good intent, and to argue about the work, never about the person.

Not welcome, anywhere in the project, are insults, harassment, discrimination, unwanted personal attention, and publishing someone's private information.

If you see or experience behaviour that breaks this, open an issue or contact the maintainer through the repository. Reports are read by the maintainer, kept as private as GitHub allows, and acted on, which can mean a warning, an edited or removed comment, or being blocked from the project.

This document follows the spirit of the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), in fewer words.
